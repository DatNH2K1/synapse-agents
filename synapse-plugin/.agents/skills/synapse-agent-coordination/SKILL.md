# Synapse Agent Coordination

This Master Skill provides resources and specialized sub-skills for multi-agent execution, editorial review, and workflow planning.

## How to use Sub-skills

When coordinating workflows, check the list below and read the specific sub-skill's instructions using the `view_file` tool before proceeding:

- **Advanced Elicitation**: Triggers self-critique, reasoning depth changes, or multi-persona panel debates.
  - File: [advanced-elicitation/SKILL.md](references/advanced-elicitation/SKILL.md)
- **Coding Level**: Adjusts AI explanation styles and details based on coding experience (Level 0-5).
  - File: [coding-level/SKILL.md](references/coding-level/SKILL.md)
- **Context Engineering**: Diagnostics tool to audit token consumption and prevent context bloat.
  - File: [context-engineering/SKILL.md](references/context-engineering/SKILL.md)
- **Editorial Review Prose**: Clinical line-editor to optimize grammar, tone, and communication style.
  - File: [editorial-review-prose/SKILL.md](references/editorial-review-prose/SKILL.md)
- **Editorial Review Structure**: Reorganizes documents for visual flow, formatting, and structural simplicity.
  - File: [editorial-review-structure/SKILL.md](references/editorial-review-structure/SKILL.md)
- **Adversarial Plan**: Creates task implementation plan artifacts with pre-mortem risk assessment.
  - File: [adversarial-plan/SKILL.md](references/adversarial-plan/SKILL.md)
- **Autoresearch**: Automated loop executing edits against git-tracked metrics (coverage, errors).
  - File: [autoresearch/SKILL.md](references/autoresearch/SKILL.md)
