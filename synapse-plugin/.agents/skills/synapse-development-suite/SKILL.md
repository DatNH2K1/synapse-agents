# Synapse Development Suite

This Master Skill provides resources and specialized sub-skills for development and project execution workflows.

## How to use Sub-skills

When performing development tasks, check the list below and read the specific sub-skill's instructions using the `view_file` tool before proceeding:

- **Quick Dev**: Implements requirements, bug fixes, or quick tweaks.
  - File: [quick-dev/SKILL.md](references/quick-dev/SKILL.md)
- **Dev Story**: Implements a structured feature story.
  - File: [dev-story/SKILL.md](references/dev-story/SKILL.md)
- **Correct Course**: Manages mid-sprint scope or requirement corrections.
  - File: [correct-course/SKILL.md](references/correct-course/SKILL.md)
- **Create Architecture**: Creates solution design decisions and technical architectures.
  - File: [create-architecture/SKILL.md](references/create-architecture/SKILL.md)
- **Better Auth**: Integrates the Better Auth framework, configuring adapters and plugins.
  - File: [better-auth/SKILL.md](references/better-auth/SKILL.md)
- **TanStack**: Implements TanStack Query, Router, or Table best practices.
  - File: [tanstack/SKILL.md](references/tanstack/SKILL.md)
- **MCP Builder**: Builds and registers new MCP servers.
  - File: [mcp-builder/SKILL.md](references/mcp-builder/SKILL.md)
- **Repo Indexer**: Scans the workspace and builds/syncs the AST dependency graph.
  - File: [repo-indexer/SKILL.md](references/repo-indexer/SKILL.md)
- **Game Development**: Game loop updates, physics simulations, canvas, and WebGL rendering.
  - File: [game/SKILL.md](references/game/SKILL.md)
- **Mobile Development**: Native and cross-platform mobile application guidelines.
  - File: [mobile/SKILL.md](references/mobile/SKILL.md)
